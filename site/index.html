Two ways in, both ending in a single .folio file.

Bring a story

A novel, a screenplay, something you wrote. The compiler builds the map, the puzzles and the prose, then proves the result is actually finishable before it ships. You set how long and how cruel it should be.

folio brief my-brief.json folio pack my-game/ my-game.folio folio validate my-game.folio

Bring a game

Already have a Z-machine game — Zork, an Inform project, something from the IF Archive? Folio runs the original binary unmodified and gives it the pictures it never had.
