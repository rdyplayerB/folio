How it works

One file per game

A .folio carries the logic, the pictures, the sound and its own walkthrough. Download it and you have the game permanently, whatever happens to this site.

Proven finishable

Before a game is certified, the engine replays its walkthrough from the beginning and has to reach the ending. No teleporting and no shortcuts. If it does not finish, it does not ship.

The real thing underneath

Classic games run their original 1980s binary, unmodified. The pictures are a layer on top, so the game you play is the one people played then.

Bring a story

A novel, a screenplay, something you wrote. The compiler builds the map, the puzzles and the prose, then proves the result is finishable before it ships. You set how long it runs and how cruel it gets.
