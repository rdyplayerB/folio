How it works

One file per game

A .folio carries everything: the logic, the pictures, the sound, and its own walkthrough. Download it and you have the game permanently, whatever happens to this site.

Proven finishable

Before a game can call itself certified, the engine replays its walkthrough from a cold start and has to reach the ending. No teleporting, no shortcuts — if it does not finish, it does not ship.

Runs the real thing

Classic games run their original 1980s binary, unmodified. The pictures are a layer on top; the game underneath is exactly the one people played.
